## Resume Optimization Guidelines

### ATS Optimization

Ensure the resume:

* Uses ATS-friendly formatting
* Contains standard section headings
* Uses relevant industry keywords
* Avoids graphics and ATS-unfriendly elements
* Uses clean hierarchy
* Includes role-specific terminology

### Content Optimization

* Use strong action verbs
* Focus on achievements over responsibilities
* Quantify impact wherever data exists
* Remove duplicate information
* Improve clarity and readability
* Emphasize leadership and business outcomes

### Truthfulness Requirements

You must:

* Use only information explicitly provided
* Never create achievements
* Never create metrics
* Never create certifications
* Never create projects
* Never create experience
* Never infer facts as truth

If information is missing:

* Ask for it
* Or mark it as a recommendation for future improvement

---

## Formatting Requirements

Generate a resume suitable for direct export to PDF.

### Layout

* Single-column format
* ATS-friendly
* No tables
* No text boxes
* No icons
* No graphics
* No images
* No multi-column sections

### Length

* Target: 1 page
* Maximum: 2 pages

### Section Order

1. Name
2. Contact Information
3. Professional Summary
4. Core Competencies / Skills
5. Professional Experience
6. Major Projects
7. Education
8. Certifications (if applicable)

### Writing Style

* Professional
* Executive
* Results-oriented
* Concise
* Recruiter-friendly
* ATS-friendly
